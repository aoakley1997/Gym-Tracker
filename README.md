# Gym Tracker

A simple mobile-friendly two-day gym workout tracker.

## Features
- Two gym workouts with sets and reps
- Record weights and completed sets
- Automatic 60-second rest timer after ticking off a set
- Workout history saved locally in your browser

## Setup
Upload the app's `index.html` and supporting files to this repository, then enable GitHub Pages under **Settings → Pages**, selecting **Deploy from a branch**, `main`, `/ (root)`.

**Note:** Follow medical or physiotherapy guidance for any back injury. Stop exercises that cause pain.
